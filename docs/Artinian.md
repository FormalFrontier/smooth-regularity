# Regularity criteria for Artinian rings

Import `SmoothRegularity.Artinian`, or the root module `SmoothRegularity`.
The module relates regularity to field structure in the local case and to
reducedness in general, using Mathlib's dimension and localization results.

## Signatures

```lean
universe u

IsArtinianRing.isRegularLocalRing_iff_isField
    (R : Type u) [CommRing R] [IsArtinianRing R] [IsLocalRing R] :
    IsRegularLocalRing R ↔ IsField R

IsArtinianRing.isRegularRing_iff_isReduced
    (R : Type u) [CommRing R] [IsArtinianRing R] :
    IsRegularRing R ↔ IsReduced R
```

`IsField R` is a proposition, rather than the data of a `Field R` structure.
`IsReduced R` says that every nilpotent element is zero. All these predicates
and the regularity classes are Mathlib's existing API; there are no new
ring predicates or global instances converting regularity to reducedness or
reducedness to regularity.

## Using each direction

For an Artinian local ring, use
`(IsArtinianRing.isRegularLocalRing_iff_isField R).mp h` to obtain `IsField R`
from `h : IsRegularLocalRing R`, and `.mpr h` in the other direction.
For an Artinian ring, use
`(IsArtinianRing.isRegularRing_iff_isReduced R).mp h` to obtain `IsReduced R`
from `h : IsRegularRing R`, and `.mpr h` in the other direction.

There is no separate `[IsNoetherianRing R]` assumption: Mathlib derives it from
Artinianity via `Mathlib.RingTheory.HopkinsLevitzki`. There is no domain,
field or nontriviality hypothesis in the global criterion. The local criterion
uses `[IsLocalRing R]`, which includes nontriviality in Mathlib.

An Artinian reduced local ring is already a field by Mathlib's
`IsArtinianRing.isField_of_isReduced_of_isLocalRing R`. That result is reused
by the local reduced-ring client, not restated or copied. Likewise, transport
along ring equivalences uses Mathlib's `IsRegularRing.of_ringEquiv` and
`IsRegularLocalRing.of_ringEquiv`; obtaining local regularity from global
regularity in a local ring uses
`IsRegularLocalRing.of_isRegularRing_of_isLocalRing`.

## Proofs

For the local criterion, Artinianity gives Krull dimension zero. Mathlib's
`isRegularLocalRing_iff` then says that the maximal ideal has span finrank
zero. The ideal is finitely generated by Noetherianity, so
`Submodule.spanFinrank_eq_zero_iff_eq_bot` identifies this condition with the
maximal ideal being zero. This is equivalent to `IsField R` by
`IsLocalRing.isField_iff_maximalIdeal_eq`.

For the global criterion, the localizations at prime ideals are Artinian local
rings. If the ring is regular, each localization at a maximal ideal is regular,
hence a field by the local criterion, and therefore reduced. Mathlib's
`isReduced_ofLocalizationMaximal` descends reducedness to the original ring.
Conversely, the localizations of a reduced ring are reduced; Artinian reduced
local rings are fields, so the local criterion and `isRegularRing_iff` give
regularity. This argument does not require nontriviality of the original ring.

## Examples and boundaries

[The ordinary-import clients](../SmoothRegularityTest/Artinian.lean) use only
the root library import and Mathlib modules for the concrete examples.

- A field in any universe is Artinian and satisfies both regularity conclusions.
- A finite indexed family of fields satisfies the global criterion, even when
  the product is not a field. The concrete ring `Fin 2 → ℚ` is Artinian and
  reduced but not a field: it is not local, by Mathlib's
  `IsLocalRing.not_isLocalRing_of_nontrivial_pi`.
- In `ZMod 4`, the element `2` is nonzero but has square zero. This ring is
  Artinian because it is finite, and it is not reduced; the global criterion
  consequently gives nonregularity. The nilpotent witness and reducedness
  obstruction do not use either regularity equivalence.
- The zero ring `PUnit` is Artinian and reduced, so the global criterion gives
  regularity. It is not a field. The theorem
  `PUnit.isRegularRing_and_not_isField` in `SmoothRegularityTest.Artinian`
  states both conclusions in every universe. The zero ring cannot satisfy
  Mathlib's `IsLocalRing`, which requires nontriviality.

The examples supply Artinianity and reducedness from Mathlib instead of
assuming regularity or field structure on a non-field product. Their regularity
conclusions use the two Artinian equivalences. No conclusion about
regular local rings being domains in arbitrary dimension, or about smoothness,
is asserted by these criteria.

## Mathlib reuse

The declarations use Mathlib's
[`RegularLocalRing.Defs`](https://github.com/leanprover-community/mathlib4/blob/83abb3e776bdefcbc447a1e44d0debe4010039e5/Mathlib/RingTheory/RegularLocalRing/Defs.lean),
including its cotangent-space characterization of regular local rings.
The Artinian input and reduced finite-product-of-fields equivalence
`IsArtinianRing.equivPi` come from
[`Artinian.Ring`](https://github.com/leanprover-community/mathlib4/blob/83abb3e776bdefcbc447a1e44d0debe4010039e5/Mathlib/RingTheory/Artinian/Ring.lean)
and
[`Artinian.Module`](https://github.com/leanprover-community/mathlib4/blob/83abb3e776bdefcbc447a1e44d0debe4010039e5/Mathlib/RingTheory/Artinian/Module.lean).
The dimension-zero characterization is supplied by
`Mathlib.RingTheory.HopkinsLevitzki` and
`Mathlib.RingTheory.KrullDimension.Zero`. Localization and descent of
reducedness use `Mathlib.RingTheory.LocalProperties.Reduced`.
The equivalences in this module are distinct from those imported results; no
claim that Mathlib supplies these two regularity equivalences is intended.
